# SOTA summits, split by association

This folder is a machine-friendly split of the worldwide **SOTA**
(Summits On The Air) summit list. The single big `summitslist.csv` is split
into one CSV per *association* so an LLM chat can load just the relevant slice
instead of the whole 20+ MB file.

> Generated by `scripts/split_summitslist.py`. Do not edit by hand — rerun the
> script to refresh. Source list dated: **SOTA Summits List (Date=05/06/2026)**.

## How it is organised

- One file per association, named `<CODE>.csv` (e.g. `OM.csv`, `DM.csv`).
- The association code is the part of `SummitCode` before the `/`
  (`OM/BA-001` → association `OM`).
- Each CSV keeps the original banner line + header, then its summit rows.
- `manifest.json` holds a **sha256 checksum** of the source `summitslist.csv`
  plus per-association counts and a UTC timestamp. If the checksum matches the
  current source, the data here is up to date.
- Encoding is clean UTF-8. (The upstream source is double-encoded mojibake;
  the script repairs it on the way in.)

## Column schema

Header row: `SummitCode,AssociationName,RegionName,SummitName,AltM,AltFt,GridRef1,GridRef2,Longitude,Latitude,Points,BonusPoints,ValidFrom,ValidTo,ActivationCount,ActivationDate,ActivationCall`

| # | Column | Meaning |
|---|--------|---------|
| 1 | `SummitCode` | Unique ID, e.g. OM/BA-001. Prefix before '/' is the association. |
| 2 | `AssociationName` | Full association name, e.g. "Germany (Low Mountains)". |
| 3 | `RegionName` | Region within the association. |
| 4 | `SummitName` | Name of the summit (may contain accented UTF-8 characters). |
| 5 | `AltM` | Altitude in metres. |
| 6 | `AltFt` | Altitude in feet. |
| 7 | `GridRef1` | Longitude (duplicate of Longitude, kept from source). |
| 8 | `GridRef2` | Latitude (duplicate of Latitude, kept from source). |
| 9 | `Longitude` | Longitude in decimal degrees (WGS84). |
| 10 | `Latitude` | Latitude in decimal degrees (WGS84). |
| 11 | `Points` | SOTA points awarded for activating the summit (1-10). |
| 12 | `BonusPoints` | Seasonal winter bonus points. |
| 13 | `ValidFrom` | Date the summit became valid (DD/MM/YYYY). |
| 14 | `ValidTo` | Date the summit stops being valid (DD/MM/YYYY; 31/12/2099 = open-ended). |
| 15 | `ActivationCount` | Number of times the summit has been activated. |
| 16 | `ActivationDate` | Date of the most recent activation (DD/MM/YYYY). |
| 17 | `ActivationCall` | Callsign of the most recent activator. |

Example row:

```
3Y/BV-001,"Bouvet Island","Bouvetøya (Bouvet Island)",Olavtoppen,780,2559,3.3565,-54.4104,3.35650,-54.41040,10,3,01/03/2018,31/12/2099,0,,
```

Notes:
- Dates are `DD/MM/YYYY`. `ValidTo = 31/12/2099` means the summit is currently valid.
- Coordinates are decimal degrees, WGS84. `GridRef1/GridRef2` duplicate `Longitude/Latitude`.
- To find a summit by code, open `<prefix>.csv` and match the `SummitCode` column.
